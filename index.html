GPU Computing · CUDA · C++↗

CUDA Kernels

GPU kernels in CUDA C++17, benchmarked on an NVIDIA Tesla T4. I optimized a parallel reduction from 59 to 227 GB/s, about 70% of peak memory bandwidth, by having each thread accumulate privately in a grid-stride loop before one shared-memory tree per block, and by sizing the grid to fill every SM. Device memory is managed with an RAII wrapper, kernels are tested against CPU references with Google Test and compute-sanitizer, and CI builds every push.

CUDAC++17Shared MemoryParallel ReductionCMakeGoogle Test
Computer Architecture · Verilog · FPGA↗

RISC-V Processor with Custom SIMD Instructions

Team of three. Extended a five-stage pipelined RV32I processor in Verilog with custom vector instructions (vdot, vadd, vmul, vsub, vdiv, vli) on 128-bit registers, targeting matrix multiplication. I co-designed the instructions, built the fetch and decode stages, and wrote the assembler. Ran on a Terasic DE2-115 FPGA at 50MHz, verified with automated Python tests against NumPy, with up to 5× speedup over scalar execution. Link opens the project report.

Control Systems · Verilog · FPGA↗

FPGA PID Controller

PID control loop in Verilog with Q8.8 fixed-point gains and 6-cycle worst-case latency (60ns at 100MHz, timing met at 127MHz on an ECP5). Saturating arithmetic throughout, a low-pass filtered derivative and an anti-windup integrator. Directed tests caught three bugs in my first version (multiply truncation, integrator wrap and rounding of small errors), now fixed and documented with before-and-after results in the README.
